TravelWise - Bootstrap Simple Version

This version uses Bootstrap 5.3.8 for the layout, cards, forms, spacing,
buttons, grid and responsive design. Only project-specific styling remains
in style.css.

Files:
index.html
style.css
script.js

Open index.html in a browser.

The Bootstrap CDN is used, so an internet connection is needed for the
Bootstrap styles/icons.

Later this frontend can connect to the Python/FastAPI backend.
